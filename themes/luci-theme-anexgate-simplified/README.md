# AnexGate Simplified LuCI Theme

Customer-specific simplified AnexGate LuCI theme scaffolded from
`luci-theme-anexgate`.

## Build Selection

Package name:

```text
luci-theme-anexgate-simplified
```

OpenWrt menuconfig location:

```text
LuCI -> Themes -> luci-theme-anexgate-simplified
```

Theme display name:

```text
AnexGate Simplified Theme
```

UCI theme entry:

```text
luci.themes.AnexGateSimplified=/luci-static/anexgate-simplified
```

## Migration Notes

This theme is the phase-one UI base for replacing the extracted ACE PHP web UI
with LuCI apps. It keeps the existing AnexGate visual structure while giving us
a separate selectable simplified theme package.
